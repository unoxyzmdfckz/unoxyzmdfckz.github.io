Networks & Cybersecurity

How devices connect, how the Internet works, and how we protect it all.

Topic 1: Introduction to Computer Networks

A computer network is a group of two or more devices connected together so they can communicate, share data, share resources, and access services.

Laptop ↔ Router ↔ Internet ↔ Server

Why Do We Need Networks?

  • Communication - messages, emails, video calls
  • Information Access - websites, databases, cloud services
  • Resource Sharing - printers, files, internet connections
  • Collaboration & Management - managing users, devices, data

Types of Networks

TypeCoverageExample
PAN (Personal)Personal areaPhone + smartwatch
LAN (Local)Small/local areaComputer laboratory
MAN (Metropolitan)City-wide areaCity government network
WAN (Wide)Large geographicThe Internet

Network Topology

Describes the physical or logical arrangement of devices: Bus, Star, Ring, Mesh.

TopologyMain AdvantageMain Disadvantage
BusLow costMain cable failure kills network
StarEasy managementCentral device dependency
RingOrganized structureDifficult to modify
MeshHighly reliableExpensive and complex

Wired vs. Wireless Media

  • Ethernet Cable - stable, fast, reliable
  • Fiber Optic Cable - very high speed, long-distance, immune to electromagnetic interference
  • Wi-Fi - radio signals for wireless devices
  • Cellular Networks - 4G, 5G for mobile devices

Network Hardware

  • NIC - Network Interface Card, allows device to connect
  • Hub - sends data to all connected devices
  • Switch - sends data intelligently to the intended device
  • Router - connects different networks together
  • Modem - connects your network to your ISP
  • Access Point - allows wireless devices to connect

MAC Address vs. IP Address

  • MAC Address - identifies the network hardware. Like the identity of a network interface.
  • IP Address - identifies location on a network. Example: 192.168.1.10

Topic 2: Internet & World Wide Web

The Internet is a global network of interconnected computer networks — a "network of networks."

Internet vs. WWW

InternetWorld Wide Web
Global network infrastructureA service that runs on the Internet
Connects networks and devicesConnects web pages via hyperlinks
Supports many services (email, FTP, etc.)Primarily accessed via web browsers
The Web depends on the Internet, but the Internet can exist without the Web.

Three Important Parts of the Web

  • Web Browser - Chrome, Firefox, Edge, Safari
  • Web Server - stores, processes, and provides websites
  • Web Protocols - HTTP, HTTPS

How Visiting a Website Works

  1. You type a URL into your browser.
  2. DNS translates the domain name into an IP address.
  3. Your browser connects and sends a request to the server.
  4. The server responds with HTML, CSS, JS, and images.
  5. Browser renders the code and displays the website.

What Is a URL?

https://www.example.com/products

https:// — Protocol: how browser & server communicate.
www.example.com — Domain: identifies the website.
/products — Path: specific page or file.

HTTP vs. HTTPS

  • HTTP - plain text, readable if intercepted
  • HTTPS - encrypted, protects passwords, personal info, payment details

DNS - Domain Name System

Computers use IP addresses, but humans prefer names like google.com. DNS acts like the Internet's contact list.

Client and Server

  • Client - requests a service (browser, mobile app, desktop software)
  • Server - provides data, resources, or services (website, game, email servers)

Static vs. Dynamic Websites

Evolution of the Web

  • Web 1.0 (Read) - mostly static information
  • Web 2.0 (Read/Write) - users post, comment, share. Social media, blogs, wikis.
  • Modern Web (Interactive) - intelligent, personalized, AI-driven, real-time collaboration

Topic 3A: Introduction to HTML

HTML stands for HyperText Markup Language. It's not a programming language — it's a markup language that structures content on the web.

HTML vs. CSS vs. JavaScript

TechnologyRoleHouse Analogy
HTMLStructure / contentWalls, rooms, roof
CSSAppearance / designPaint, decor, carpet
JavaScriptBehavior / interactivityElectricity, moving doors

Tags vs. Elements

  • Tag - a marker like <p>
  • Element - the complete structure: <p>Hello</p> (opening tag + content + closing tag)

Void Elements

Some tags don't contain text and don't need closing tags: <br>, <img>, <hr>.

Basic Document Structure

<!DOCTYPE html>
<html>
  <head>
    <title>My First Web Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my webpage.</p>
  </body>
</html>

Topic 3B: Introduction to CSS

CSS stands for Cascading Style Sheets. It controls the appearance, positioning, and layout of HTML elements.

HTML = What is on the page. CSS = How it looks.

Why CSS?

  • Visual appeal - transforms plain HTML into attractive designs
  • Consistency - uniform branding across pages
  • Separation - content detached from styling
  • Reusability - write once, apply everywhere

Anatomy of a CSS Rule

p {
  color: blue;
  font-size: 20px;
}
  • Selector - p (which element to style)
  • Property - color, font-size
  • Value - blue, 20px
  • Declaration - property + value + semicolon

Three Primary Selectors

SelectorSyntaxTargets
ElementpAll tags of a specific type
Class.importantReusable groups (begin with period)
ID#main-titleOne unique element (begin with hash)

Common CSS Properties

PropertyPurpose
colorText color
background-colorElement background
font-sizeText size
font-familyTypeface
margin / paddingSpacing outside / inside
borderOutline around element

Three Ways to Apply CSS

  • Inline - inside the HTML tag (quick for testing, hard to maintain)
  • Internal - inside <style> in the head (good for single pages)
  • External - separate .css file linked with <link> (recommended — cleaner, reusable)

What Does "Cascading" Mean?

When multiple rules target the same element, the browser decides which wins based on:

  1. Importance - is the rule marked vital?
  2. Specificity - IDs beat Classes. Classes beat Elements.
  3. Source Order - the last rule loaded takes effect.

Topic 4: Types of Cyber Threats

A cyber threat compromises digital systems and users at every level — individuals, organizations, and society.

Malicious Software (Malware)

TypeBehavior
Computer VirusAttaches to legitimate files, spreads on execution
Computer WormReplicates and spreads independently
Trojan HorseDisguises as legitimate software
RansomwareEncrypts files, demands payment
SpywareSecretly monitors activity
KeyloggerRecords keystrokes to capture passwords

Social Engineering

Psychological manipulation to trick people into revealing information or bypassing security.

  • Phishing - fake messages/websites tricking users into providing credentials
  • Spear Phishing - highly targeted phishing for a specific person or organization
  • Smishing - phishing through SMS/text messages
  • Vishing - phishing through voice calls
  • Pharming - secretly redirecting users to fraudulent sites

Network & Access Attacks

  • DoS (Denial-of-Service) - overloads a system to make it unavailable
  • DDoS - same but from thousands of compromised devices
  • MITM (Man-in-the-Middle) - secretly intercepts communication

Data & Internal Risks

  • Data Breach - unauthorized access and exposure of sensitive info
  • Insider Threat - authorized users misusing their access

The Golden Rule of Defense

  1. STOP - pause before reacting to urgent demands
  2. THINK - evaluate the source for suspicious signs
  3. VERIFY - confirm authenticity through official channels

Topic 5: Categories of Cybersecurity

Cybersecurity protects computers, networks, and data from unauthorized access or damage. It is divided into categories for specialized protection.

1. Network Security

Protects computer networks from unauthorized access and disruptions.

Measures: Firewalls, network monitoring, intrusion detection, secure Wi-Fi, segmentation.

2. Information Security

Protects digital and physical information from theft or alteration. Uses the CIA Triad:

  • Confidentiality - access restricted to authorized personnel
  • Integrity - information remains completely unchanged
  • Availability - information accessible when strictly needed

3. Application Security

Protects software and web applications from vulnerabilities.

Targets: Websites, mobile apps, online banking.

Defenses: Secure coding, input validation, software updates.

4. Endpoint Security

Protects individual devices connected to the network.

  • Laptops - antivirus installation required
  • Smartphones - screen locks enforced
  • Tablets - device encryption enabled
  • Printers - security firmware updated

5. Cloud Security

Protects data, applications, and services hosted in cloud environments.

Protected services: Google Drive, OneDrive, online databases.

Measures: Strong authentication, data encryption, automated backups.

6. Identity & Access Management (IAM)

Controls identities and defines access permissions.

  • Authentication - "Who are you?"
  • Authorization - "What are you allowed to do?"

7. Operational Security

Protects daily processes and procedures.

Defense in Depth

Multiple layers work together. If one fails, others protect.

  • User - Strong passwords + MFA
  • Device - Antivirus + Updates
  • Network - Firewalls + Monitoring
  • Application - Secure coding
  • Data - Encryption + Backups

Example: Online Banking Account

One system involves multiple cybersecurity categories: phone screen lock, password & OTP/MFA, secure banking app, encrypted connection, protected bank servers.

Topic 6: Cybersecurity Technologies

Hardware, software, and techniques designed to defend digital infrastructure.

Cyber Threat → Security Tech → Protection. Example: Malware → Antivirus → Removal.

Common Technologies

TechnologyMain Purpose
FirewallControls incoming and outgoing network traffic
AntivirusDetects, prevents, removes malicious software
EncryptionProtects information from unauthorized viewing
Authentication / MFAVerifies user identity through multiple factors
VPNCreates a protected, encrypted network connection

How a Firewall Works

  1. Request - traffic reaches firewall
  2. Inspect - checked against rules
  3. Decide - allow or block
A firewall does not protect against every threat. It cannot stop a user from voluntarily downloading a malicious file.

Antivirus Core Loop

Scan → Detect → Quarantine → Remove.

Regular updates are crucial to recognize new threat signatures.

Encryption

Converts readable information (plaintext) into an unreadable form (ciphertext).

MY PASSWORD → (encryption key) → 7x@K92#m...

Where used: messaging, online shopping, online banking, web browsing, file storage, device data.

Authentication Factors

  • Something You Know - password, PIN
  • Something You Have - smartphone, security key, hardware token
  • Something You Are - fingerprint, facial recognition, biometrics

Multi-Factor Authentication (MFA)

Requires two or more different authentication factors.

Password Managers

Securely stores and manages passwords. Generates strong passwords, stores credentials safely, autofills login forms, reduces password reuse.

Virtual Private Network (VPN)

Without VPNWith VPN
Device → InternetDevice → VPN Server → Internet
Traffic is exposed and observableTraffic is encrypted and routed securely

IDS vs. IPS

IDSIPS
Intrusion Detection SystemIntrusion Prevention System
Detects and alertsDetects and blocks

SSL / TLS

  • HTTP - unsecured connection
  • HTTPS - HTTP protected by TLS

Digital Certificates

Establishes the identity of a website or server. Like an online ID card — helps the browser verify it's communicating with the legitimate website, not an imposter.

Backup and Recovery

A backup is a copy of important data stored separately from the original.

Why backup? To recover if the original is deleted, corrupted, lost, or encrypted by ransomware.

TypeDescription
Full BackupCopies all selected data completely
IncrementalCopies only data changed since last backup
Cloud BackupStores copies off-site via cloud service
ExternalStores data on physical, detached media
A backup is useful only if it can actually be restored. Test regularly.

Access Control

RoleAccess Level
StudentView own grades

RegistrarManage broad academic records
AdministratorManage core system functions
Principle of Least Privilege: Give users only the access they strictly need.

Security Updates & Patches

Vulnerability → Patch Released → Installation → Secured.

SIEM

Security Information and Event Management — collects and analyzes logs globally, identifies unusual patterns, and generates alerts.

The Reality

Technology alone is not enough. Security fails primarily due to human error, phishing susceptibility, weak password habits, and unsafe downloads.

People + Processes + Technology = Cybersecurity
