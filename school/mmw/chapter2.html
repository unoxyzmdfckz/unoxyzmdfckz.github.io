2.1 Mathematics as a Language

What is Language?

Language is a systematic means of communicating ideas or feelings using conventionalized signs, sounds, gestures, or marks with understood meanings.

According to Dr. Burns, the language of mathematics makes it easy to express the kinds of thoughts mathematicians like to express. It is:

  1. Precise – able to make very fine distinctions
  2. Concise – able to say things briefly
  3. Powerful – able to express complex thoughts with relative ease
Math language is precise, concise, and powerful — klaro, mubo, pero ma express niya ang complex ideas.

Classifications of Symbols

1. Numbers

A number is a mathematical object used to count, quantify, and label another object. These include:

  • Real Numbers (ℝ) – combination of whole numbers, fractions, and decimals. All types of numbers.
  • Rational Numbers (ℚ) – can be written as fractions. When converted to decimals, either terminating (may end) or repeating (gabalik-balik).
  • Irrational Numbers (ℚ′) – cannot be written as fractions. Decimals are non-terminating and non-repeating.
  • Integers (ℤ) – whole numbers from −∞ to +∞
  • Natural Numbers (ℕ) – numbers from 1 to +∞
1/2 = 0.5 is rational (terminating). 1/3 = 0.333… is rational (repeating). √2 = 1.41421356… is irrational (no end, no repeat). π = 3.14159… is irrational.
Rational decimals → may end OR ga-repeat. Irrational decimals → walay end UG walay repeat.

2. Operation Symbols

  • Addition (+)
  • Subtraction (−)
  • Multiplication (× or ·)
  • Division (÷ or /)
  • Exponentiation (xⁿ) — x is the base, n is the exponent
    • If exponent is 2 → "squared" (e.g., 5² = 25)
    • If exponent is 3 → "cubed" (e.g., 2³ = 8)

3. Relation Symbols

  • Greater than or equal (≥)
  • Less than or equal (≤)
  • Equal (=)
  • Not equal (≠)
  • Similar (∼)
  • Approximately equal (≈)
  • Congruent (≡)

Definitions:

  • Congruent figures – same shape and size
  • Similar figures – same shape, but not necessarily same size
  • Approximately equal – close enough in value that the difference is insignificant in practical terms
Two triangles with angles 30°-60°-90° but different side lengths are similar. Two triangles with angles 30°-60°-90° and the same side lengths are congruent. 99.8 ≈ 100 because the difference is negligible.

4. Grouping Symbols

  • Parentheses ( )
  • Curly brackets / braces { }
  • Square brackets [ ]
In 2 × (3 + 4), the parentheses tell you to add first: 3 + 4 = 7, then 2 × 7 = 14.

5. Variables

Used when quantities take different values. Usually letters of the alphabet like x and y.

In the equation y = 2x + 1, x and y are variables. If x = 3, then y = 2(3) + 1 = 7. If x = 5, then y = 11.

6. Set Theory Symbols

  • Subset (⊆)
  • Union (∪)
  • Intersection (∩)
  • Element (∈)
  • Not element (∉)
  • Empty set (∅)

7. Logic Symbols

  • Implies (⇒)
  • Equivalent (⇔)
  • And (∧)
  • Or (∨)
  • For all (∀)
  • There exists (∃)
  • Therefore (∴)

8. Statistical Symbols

  • Sample mean (x̄) – average of a group of numbers. Add all numbers, divide by how many there are.
  • Population mean (μ) – average of the entire population.
  • Median (x̄) – middle value of a group of numbers. For odd counts, it's the exact middle. For even counts, average the two middle values.
  • Population standard deviation (σ) – measures how spread out the values are from the mean. It requires several steps: find the mean, subtract the mean from each value, square each result, average those squares, then take the square root. This can't be reduced to a single quick example without doing the full computation.
  • Summation (Σ) – the sum of all. Add all numbers.
  • Factorial (n!) – multiply the number down to 1.
Sample mean of {2, 4, 6, 8} = (2+4+6+8)/4 = 20/4 = 5. Median of {3, 5, 7} = 5. Median of {3, 5, 7, 9} = (5+7)/2 = 6. Summation: Σ{1,2,3} = 1+2+3 = 6. Factorial: 4! = 4×3×2×1 = 24.

Mathematical Expression vs. Mathematical Sentence

TypeDefinition
Mathematical Expression A mathematical phrase that combines symbols for numbers (constants), variables, operations, grouping symbols, and other punctuation. Does not state a complete thought. (Analog of a "noun")
Mathematical Sentence Makes a statement about two expressions. Uses numbers, variables, or both. Uses symbols or words like equals, greater than, or less than. States a complete thought.
"3x + 5" is an expression (no equal sign, incomplete thought). "3x + 5 = 14" is a sentence (complete thought, has an equal sign).

Types of Sentences

  • Open Sentence – Uses variables; not known whether true or false.
  • Closed Sentence – Known to be either true or false.
"x + 2 = 5" is open because we don't know x yet. "10 − 1 = 7 + 2" is closed and true because 9 = 9. "10 is an odd number" is closed and false because 10 is even.

2.2 Four Basic Concepts: Set, Relation, Function, and Binary Operation

Sets

A set is a well-defined collection of distinct objects. The objects can be anything: numbers, letters, movies, people, animals, etc.

Each object belonging to a set is called the element or member of the set.

Ang set kay grupo sa mga butang. Ang matag object kay gitawag nga element or member.

Notation:

  • ∈ means "is an element of"
  • ∉ means "is not an element of"
C = {1, 2, 3}. Then 1 ∈ C (1 is in the set) and 0 ∉ C (0 is not in the set).

Two Ways of Specifying a Set

MethodDescription
Roster MethodElements are enumerated, separated by commas, enclosed in braces { }. More on numbers.
Rule MethodA phrase is used to describe all elements in the set. More on words.
Roster: A = {1, 2, 3, 4, 5}. Rule: A = {x | x is a natural number less than 6}.

Definition of Terms

  • Empty set / Null set – set with no elements; denoted by ∅ or { }.
  • Singleton set – set with only one element.
  • Universal set (U) – set containing all elements under consideration.
  • Finite set – consists of a finite number of elements.
  • Infinite set – not finite.
∅ = { } is empty. {0} is a singleton set (it has one element, 0). Examples of infinite sets: ℝ, ℤ, ℕ, ℚ.
0 ≠ ∅. The set {0} is a singleton set, while ∅ is empty.

Set Relationships

  • Equal sets (A = B) – A and B have exactly the same elements
  • Equivalent sets – A and B have the same number of elements
  • Subset (A ⊆ B) – every element of A is also an element of B
  • Proper subset (A ⊂ B) – A ⊆ B and A ≠ B
A = {1, 2, 3} and B = {1, 2, 3} → A = B (equal). A = {−1, 1/2, π} and B = {q, r, t} → equivalent (both have 3 elements). {1, 2} ⊆ {1, 2, 3} because every element of {1, 2} is in {1, 2, 3}.

Important Facts

  1. The null set is a proper subset of every set.
  2. Any set is a subset of itself.
  3. A set with n elements has a total of 2ⁿ subsets.

Power Set – set of all subsets of a set. Notation: P(A).

If A = {1, 2, 3}, then |A| = 3, so 2³ = 8 subsets. P(A) = {∅, {1}, {2}, {3}, {1,2}, {2,3}, {1,3}, A}.

Operations on Sets

  • Union (A ∪ B) – all elements belonging to either A or B or both.
  • Intersection (A ∩ B) – all elements common to both A and B.
  • Complement (A′) – all elements in the universal set U but not in A.
U = {1, 2, 3, 4, 5}, A = {1, 5}, B = {2, 3, 5}. A ∪ B = {1, 2, 3, 5} (combine, remove duplicates). A ∩ B = {5} (only common element). B′ = {1, 4} (in U but not in B). A ∪ B′ = {1, 5} ∪ {1, 4} = {1, 4, 5}.

Cartesian Product

The Cartesian product A × B is the set of all ordered pairs (a, b) where a ∈ A and b ∈ B.

A = {1, 5}, B = {2, 3, 5}. A × B = {(1,2), (1,3), (1,5), (5,2), (5,3), (5,5)}. Note: A × B ≠ B × A because ordered pairs are direction-sensitive. {a, b} = {b, a}, but (a, b) ≠ (b, a).

Relations and Functions

A relation is a relationship between sets of information. A relation R from set X to set Y is a subset of X × Y.

If (x, y) ∈ R, then x is related to y.

Domain and Image

  • Domain of R, D(R) – set of all first coordinates: D(R) = {x : x ∈ X, (x, y) ∈ R}
  • Image of R, I(R) – set of all second coordinates: I(R) = {y : y ∈ Y, (x, y) ∈ R}
R = {(1, 3), (1, 4), (2, 5)}. Domain = {1, 2}. Image = {3, 4, 5}.

Function

A function is a relation where each input is related to exactly one output.

A = {(1, 3), (1, 4), (2, 5)} is NOT a function because input 1 has two outputs (3 and 4). B = {(a, 1), (b, 1), (c, 2)} IS a function because each input has exactly one output.

Binary Operations

Let S be a non-empty set. A binary operation * on S is a function from S × S into S. The result is always still inside S. We say S is closed under *.

Addition on ℝ: 2 + 3 = 5, which is still a real number → closed. Subtraction on ℕ: 1 − 2 = −1, which is NOT a natural number → not closed. So subtraction is not a binary operation on ℕ.

Properties of Binary Operations

  1. Commutative Property – ∀x, y ∈ S, x * y = y * x.
    Addition is commutative: 2 + 3 = 3 + 2. Subtraction is not: 5 − 3 ≠ 3 − 5.
  2. Associative Property – ∀x, y, z ∈ S, (x * y) * z = x * (y * z).
    Addition is associative: (2 + 3) + 4 = 2 + (3 + 4) = 9. Subtraction is not: (5 − 3) − 1 = 1, but 5 − (3 − 1) = 3.

2.3 Elementary Mathematical Logic

Logic is the basis of all mathematical statements and arguments. Its basic rules are essential to understand mathematical statements such as:

  • "There exists an integer n such that n² = n"
  • "If x is an integer, then x + 1 is also an integer"
  • "For all real number x with x < 0, x² > 0"

Artificial intelligence, system specifications, computer science, and allied fields are just some of the areas where logic is absolutely important.

Logic is the basis sa tanan mathematical statements and arguments. Importante kaayo sa AI, computer science, ug uban pa.

Propositions

A proposition is a declarative sentence that is either true or false, but not both.

The truth or falsity of a statement is called its truth value.

  • True (T) – if it is a true proposition
  • False (F) – otherwise

Letters are commonly used to denote propositional variables such as p, q, r, and s.

Examples

Propositions:

  1. Lapasan is one of the barangays in Cagayan de Oro City. → True
  2. Green is a primary color. → False
  3. 3 + 1 = 4 → True
  4. 3 + 3 = 9 → False

Not propositions:

  1. Answer this correctly. → Command, not declarative
  2. What is your name? → Question, not declarative
  3. 3x + 1 = y → Truth value depends on x and y
  4. x² > 10 → Truth value depends on x
"3 + 3 = 9" is a proposition because it's a declarative sentence. It's just a false one. But "x + 1 = 5" is not a proposition because we don't know x yet.

Basic Logical Operators

Compound propositions are formed by combining one or more existing propositions using logical operators or connectives.

OperatorRepresentationMeaning
Negation~p"not p"
Conjunctionp ∧ q"p and q"
Disjunctionp ∨ q"p or q"
Conditionalp → q"if p, then q"
Biconditionalp ↔ q"p if and only if q"

Examples with p: "It is sunny today" and q: "I need to go to work"

Negation: ~p = "It is not sunny today." If p is true, ~p is false.
Conjunction: p ∧ q = "It is sunny today and I need to go to work." True only if both are true.
Disjunction: p ∨ q = "It is sunny today or I need to go to work." True if at least one is true.
Conditional: p → q = "If it is sunny today, then I need to go to work." False only when p = T and q = F.
Biconditional: p ↔ q = "It is sunny today if and only if I need to go to work." True when both have the same truth value.

Tautology, Contradiction, and Contingency

  • Tautology – always true, no matter what the truth values are.
  • Contradiction – always false.
  • Contingency – neither a tautology nor a contradiction (mixed).
Tautology: p ∨ ~p (always true).
Contradiction: p ∧ ~p (always false).
Contingency: p ∧ q (true in some rows, false in others).

Predicates and Quantifiers

A predicate is a sentence containing variables. Its truth value depends on the values assigned to the variables.

P(x): "x + 2 = 10." If x = 8, P(8) is true. If x = 5, P(5) is false. So "x + 2 = 10" is a predicate, not a proposition — until we assign a value to x.

A counterexample is a value that makes the statement false.

Quantifiers

Quantifiers describe how often a predicate is true over a domain (set of values).

Universal Quantifier (∀)

"For all x, P(x)" — ∀x, P(x). True only if P(x) is true for every value in the domain.

P(x): "2x > x" over positive integers. For every positive integer, 2x > x holds. So ∀x, P(x) is true.

P(x): "x² < x³" over all rational numbers. Try x = −1: (−1)² = 1, (−1)³ = −1, and 1 < −1 is false. So ∀x, P(x) is false, and x = −1 is a counterexample.

Existential Quantifier (∃)

"There exists x such that P(x)" — ∃x, P(x). True if at least one value in the domain makes P(x) true.

P(x): "2x³ < 1" over real numbers. Try x = 0: 2(0)³ = 0 < 1, true. So ∃x, P(x) is true.

Q(x, y): "x² = y³" over integers where x ≠ y. Try x = 8, y = 4: 8² = 64 and 4³ = 64. True and x ≠ y. So ∃x, y, Q(x,y) is true.
