Unsa ang Language?

Ang language kay systematic means of communicating ideas or feelings by the use of conventionalized signs, sounds, gestures, or marks having understood meanings.

According to Dr. Burns, ang language sa mathematics makes it easy to express the kinds of thoughts that mathematicians like to express. It is:

  1. Precise – able to make very fine distinctions
  2. Concise – able to say things briefly
  3. Powerful – able to express complex thoughts with relative ease

Classifications of Symbols

1. Numbers

A number is a mathematical object used to count, quantify, and label another object. These include:

  • Real Numbers (ℝ) – combination sa whole numbers, fractions, and decimals. Tanan types of numbers.
  • Rational Numbers (ℚ) – numbers in fractions nga pag i-convert into decimals either terminating (naay end, like 3.33) or repeating (gabalik-balik, like 3.333333…)
  • Irrational Numbers (ℚ′) – cannot be written as fractions. Decimals are non-terminating and non-repeating (e.g., π = 3.14159…). Walay end ug walay repetition.
  • Integers (ℤ) – whole numbers from −∞ to +∞
  • Natural Numbers (ℕ) – numbers from 1 to +∞

Difference sa Rational ug Irrational:

  • Rational decimals → naay end OR ga-repeat
  • Irrational decimals → walay end UG walay repeat

2. Operation Symbols

  • Addition (+)
  • Subtraction (−)
  • Multiplication (× or ·)
  • Division (÷ or /)
  • Exponentiation (xⁿ) — x is the base, n is the exponent
    • Kung 2 ang exponent → “squared”
    • Kung 3 ang exponent → “cubed”

3. Relation Symbols

  • Greater than or equal (≥)
  • Less than or equal (≤)
  • Equal (=)
  • Not equal (≠)
  • Similar (∼)
  • Approximately equal (≈)
  • Congruent (≡)

Notes:

  • Congruent figures – same shape and size
  • Similar figures – same shape, pero dili necessarily same size
  • Approximately equal – close enough in value, ang difference insignificant na sa practical terms (e.g., 99.8 or 99.9 ≈ 100)

4. Grouping Symbols

  • Parentheses ( )
  • Curly brackets / braces { }
  • Square brackets [ ]

Used when quantities take different values. Usually letters of the alphabet like x and y.

Mga letters nga ginagamit to represent unknown values.

8. Statistical Symbols

  • Sample mean (x̄) – average sa isa ka group of numbers. I-add tanan numbers then i-divide sa kung pila kabuok.
  • Population mean (μ) – average sa tanan gyud
  • Median (x̄) – middle value sa group of numbers. Pag odd count, dali ra ma-identify. Pag even, naay formula.
  • Population standard deviation (σ) – lisod i-explain, naay formula. I-suggest watch YouTube.

  • Factorial (n!) – i-multiply ang number paubos hangtod 1. Example: 4! = 4 × 3 × 2 × 1 = 24

Mathematical Expression vs. Mathematical Sentence

Type Definition
Mathematical Expression A mathematical phrase that comprises a combination of symbols that can designate numbers (constants), variables, operations, symbols of grouping, and other punctuation. Does not state a complete thought. (Analog of a “noun”)
Mathematical Sentence Makes a statement about two expressions. Uses numbers, variables, or both. Uses symbols or words like equals, greater than, or less than. States a complete thought.

Meaning niya is

  • Mathematical Expression – equation pero walay equal sign (=). Naa numbers and variables pero walay equal sign. Diritso ra ma-identify.
  • Mathematical Sentence – complete equation, naay equal signs, everything including greater than and less than.

Types of Sentences

  • Open Sentence – Uses variables; not known whether true or false. Gagamit ug mga variables nga unknown like 4n − 2x = 4. Wala gibutang kung unsa value sa n ug x.
  • Closed Sentence – Known to be either true or false. Ma-solve nimo sya and ma-identify nimo kung sakto ba ang answer or not.

Example

Label each as open or closed. For closed sentences, identify if true or false.

  1. 10 is an odd number. → Closed – False
  2. 4 + 5x = 9 → Open
  3. 10 − 1 = 7 + 2 → Closed – True
  4. 6 − x = 5 → Open
  5. The square root of 4x is 2. → Open

2.2 Four Basic Concepts: Set, Relation, Function, and Binary Operation

Sets

A set is a well-defined collection of distinct objects. The objects can be anything: numbers, letters, movies, people, animals, etc.

Each object belonging to a set is called the element or member of the set.

Meaning kay ang set kay grupo sa mga butang — numbers, letters, movies, people, animals. Ang matag object kay gitawag nga element or member.

Notation:

  • ∈ means “is an element of”
  • ∉ means “is not an element of”

Example: C = set of counting numbers less than 4 = {1, 2, 3}

  • 1 ∈ C
  • 0 ∉ C

Two Ways of Specifying a Set

Method Description
Roster Method Elements are enumerated, separated by a comma, enclosed in a pair of braces { }. More on numbers.
Rule Method A phrase is used to describe all the elements in the set. More on words.

Definition of Terms

  • Empty set / Null set – set with no elements; denoted by ∅ or { }. Walay sulod.
  • Singleton set – set with only one element. Pag isa ra ka element ang naa sulod.
  • Universal set (U) – set containing all elements under consideration
  • Finite set – consists of a finite number of elements
  • Infinite set – not finite

Set Relationships

  • Equal sets (A = B) – A and B have exactly the same elements
  • Equivalent sets – A and B have the same number of elements
  • Subset (A ⊆ B) – every element of A is also an element of B
  • Proper subset (A ⊂ B) – A ⊆ B and A ≠ B

Important Facts

  1. The null set is a proper subset of every set.
  2. Any set is a subset of itself.
  3. A set with n elements has a total of 2ⁿ subsets.

Operations on Sets

Let A and B be two arbitrary sets.

  • Union (A ∪ B) – set containing all elements which belong to either A or B or both. I-combine tanan numbers, basta dili magbalik-balik.
  • Intersection (A ∩ B) – set of all elements common to both A and B. Kung unsay naa sa A naa pud sa B.
  • Complement (A′) – set of all elements in the universal set U but not in A

Example

Consider U = {1, 2, 3, 4, 5}, A = {1, 5}, B = {2, 3, 5}

  1. A ∪ B = {1, 5} ∪ {2, 3, 5} = {1, 2, 3, 5}
  2. A ∩ B = {1, 5} ∩ {2, 3, 5} = {5}
  3. B′ = {2, 3, 5}′ = {1, 4}
  4. A ∪ B′ = {1, 5} ∪ {1, 4} = {1, 4, 5}

another example:

  • A = {1,5}, B = {1,2,3,4}
  • A ∪ B = {1,2,3,4,5} → naay 1 sa both pero isa ra gibutang
  • A = {3,4}, B = {1,2,4}
  • A ∩ B = {4} → isa ra ka element kay mao raman common

Cartesian Product

Let A and B be two non-empty sets. The Cartesian product of A and B, denoted A × B, is the set of all ordered pairs (a, b) where a ∈ A and b ∈ B.

Meaning niya is I-pair nimo tanan numbers under set A and set B.

Example

U = {1, 2, 3, 4, 5}, A = {1, 5}, B = {2, 3, 5}

  1. A × B = {(1,2), (1,3), (1,5), (5,2), (5,3), (5,5)}
  2. A × A = {(1,1), (1,5), (5,1), (5,5)}
  3. B × A = {(2,1), (2,5), (3,1), (3,5), (5,1), (5,5)}

Relations and Functions

A relation is a relationship between sets of information. In mathematics, a relation R from set X to set Y is a subset of X × Y.

If (x, y) ∈ R, then we say that x is related to y.

Domain and Image

  • Domain of R, D® – set of all first coordinates in the ordered pairs in R
    • D® = {x : x ∈ X, (x, y) ∈ R}
  • Image of R, I® – set of all second coordinates in the ordered pairs in R
    • I® = {y : y ∈ Y, (x, y) ∈ R}

Meaning niya is

  • Domain – set of all first elements. Example: R = {1,2} {5,3} = {1,5}
  • Image – set of all second elements

Function

A function is a relation where each input is related to exactly one output.

Meaning niya is each input must be related to one output. Dili pwede duha ka output ang isa ka input.

Binary Operations

Let S be a non-empty set. A binary operation * on S is a function from S × S into S such that for x, y ∈ S, we have x * y for *(x, y).

The image of * is a subset of S. Thus, we say that **S is closed under ***.

Meaning niya is it takes two elements from a set and combines them to produce another element still in the same set.

Examples

  1. The usual addition (+), subtraction (−), and multiplication (·) are binary operations on the set ℝ of real numbers.
    • Meaning niya is mag-add ka ug both real numbers, ang result is still a real number.
  2. Subtraction (−) and division (÷) are not binary operations on ℕ since 1 − 2 ∉ ℕ and 2 ÷ 3 ∉ ℕ.
    • Meaning niya is on natural numbers, it is not always valid.
  3. Let P be the set of all sets. Union (∪) and intersection (∩) are binary operations on P.

Properties of Binary Operations

  1. Commutative Property
    A binary operation is commutative if ∀x, y ∈ S, x * y = y * x.

    • Means that order doesn’t matter, still the same answer. Bahalag magkabali-bali ilang form sa equation, basta same ra gihapon ang answer, commutative.

  2. Associative Property
    A binary operation * on S is associative if ∀x, y, z ∈ S, (x * y) * z = x * (y * z).

    • That means that grouping doesn't matter. Diri kay ga-involve ug parentheses, focus only ka ani sa parentheses, then apply the commutative property.

2.3 Elementary Mathematical Logic

Logic is the basis of all mathematical statements and arguments. Its basic rules are essential to understand mathematical statements such as:

  • “There exists an integer n such that n² = n”
  • “If x is an integer, then x + 1 is also an integer”
  • “For all real number x with x < 0, x² > 0”

Artificial intelligence, system specifications, computer science, and allied fields are just some of the areas where logic is absolutely important.

Ang logic kay basis sa tanan mathematical statements and arguments. Importante kaayo sa AI, computer science, ug uban pa.

Propositions

A proposition is a declarative sentence that is either true or false, but not both.

The truth or falsity of a statement is called its truth value.

  • True (T) 0 if it is a true proposition
  • False (F) – otherwise

Letters are commonly used to denote propositional variables such as p, q, r, and s.

Ang proposition kay declarative sentence either true or false. Ma-identify nimo kung tinood ba or dili.

Example (Propositions)

  1. Lapasan is one of the barangays in Cagayan de Oro City. → True
  2. Green is a primary color. → False
  3. 3 + 1 = 4 → True
  4. 3 + 3 = 9 → False

Example (Not Propositions)

  1. Answer this correctly. → Not declarative (command)
  2. What is your name? → Not declarative (question)
  3. 3x + 1 = y → Truth value cannot be determined
  4. x² > 10 → Truth value cannot be determined

Basic Logical Operators

Compound propositions are formed by combining one or more existing propositions using logical operators or connectives.

Operator Representation Meaning
Negation ~p “not p”
Conjunction p ∧ q “p and q”
Disjunction p ∨ q “p or q”
Conditional p → q “if p, then q”
Biconditional p ↔ q “p if and only if q”

Examples

Negation:

  • p: It is sunny today.
  • ~p: It is not the case that it is sunny today. (or “It is not sunny today.”)
  • Not p or the opposite of p. If p is true, then ~p is false.

Conjunction:

  • p: It is sunny today.
  • q: I need to go to work.
  • p ∧ q: It is sunny today and I need to go to work.
  • True if both p & q are true.

Disjunction:

  • p: It is sunny today.
  • q: I need to go to work.
  • p ∨ q: It is sunny today or I need to go to work.
  • True if at least one of p and q are true.

Conditional:

  • p: It is sunny today.
  • q: I need to go to work.
  • p → q: If it is sunny today, then I need to go to work.
  • False only when p = T and q = F. True ang answer if wala sya nasunod, bahalag magkabaliktad pa ang duha if p = F and q = T, then true rajud sya.

Biconditional:

  • p: I will graduate on time.
  • q: I will pass all the subjects this semester.
  • p ↔ q: I will graduate on time if and only if I will pass all the subjects this semester.
  • If p and q is constant like same rajud ilang value either true and true or false and false, then ang answer is true. But if inconsistent, then false sya diritso.

Predicates and Quantifiers

A predicate is a sentence containing variables. Examples:

  • “x is a real number”
  • “y + 2 = 10”
  • “x − y > z”

Its truth value depends on the values assigned to the variables. A counterexample is a value assigned to a variable for which the statement is false.

A predicate is also known as a propositional function, usually denoted by P(x), Q(x,y), R(x,y,z), etc.

Quantifiers

Quantifiers refer to the amount to which a predicate is true over a particular domain of discourse (or simply, domain) — the set of values for which the statement is defined.

Universal Quantifier (∀)

Given a predicate P(x), the statement “for all x, P(x)”, denoted by ∀x, P(x), is the universal quantification of P(x).

The symbol ∀ is the universal quantifier.

It can also be stated as:

  • “for every integer x, P(x)”
  • “for each x, P(x)”
  • “for any x, P(x)”

Example:
Let P(x) be “2x > x.” What is the truth value of ∀x, P(x) if the domain is the set of all positive integers?

Solution: Since “2x > x” is true for all positive integer x, ∀x, P(x) is true.

Example:
What is the truth value of ∀x, (x² < x³) if the domain is the set of all rational numbers?

Solution: “x² < x³” is not true for every rational number x, because (−1)² < (−1)³ is false. Thus, ∀x, (x² < x³) is false, and x = −1 is a counterexample.

Existential Quantifier (∃)

Given a predicate P(x), the proposition “there exists an element x in the domain such that P(x)” or “for some x, P(x)”, denoted by ∃x, P(x), is the existential quantification of P(x).

The symbol ∃ is the existential quantifier.

It can also be stated as:

  • “there is an x such that P(x)”
  • “there is at least one x such that P(x)”

∃x, P(x) is true if and only if there is at least one value of x in the domain that makes P(x) true.

Example:
What is the truth value of ∃x, (2x³ < 1) if the domain is the set of all real numbers?

Solution: Since 2x³ < 1 is sometimes true for the domain of real numbers, for example, for x = 0, then ∃x, (2x³ < 1) is true.

Example:
Let Q(x,y) be the predicate “x² = y³.” What is the truth value of ∃x,y, Q(x,y) if the domain is the set of all integers and x ≠ y?

Solution: Because there are values in the stated domain that satisfy x² = y³ such that x ≠ y, like x = 8 and y = 4, we can say that ∃x,y, Q(x,y) is true.
